# 季度深度宏观报告 Prompt

## Automation 执行协议

本文件用于 Codex cron automation。automation 应每周五 10:30 按安装时确认的 IANA 时区运行一次。每次运行时必须使用 automation 外层 prompt 指定的时区判断日期；如果外层 prompt 未指定时区，默认使用 `America/New_York`。

### 1. 运行窗口

- 只在 1 月、4 月、7 月、10 月的 22 日至月末之间生成季报。
- 如果不在窗口内，直接结束；不要写文件、不要 commit、不要 push。
- 如果已经进入窗口，但关键数据尚未发布，仍然生成报告，并在报告的“数据基准与数据完整性说明”中明确写“尚未发布”。

### 2. 目标季度、目标文件与去重

- 输出目录：`macro-reports/`。
- 如果运行月份是 1 月，目标报告期是上一年 Q4，文件名为 `YYYY-q4-quarterly-deep-macro-report.md`，其中 `YYYY` 是上一年。
- 如果运行月份是 4 月，目标报告期是当年 Q1，文件名为 `YYYY-q1-quarterly-deep-macro-report.md`。
- 如果运行月份是 7 月，目标报告期是当年 Q2，文件名为 `YYYY-q2-quarterly-deep-macro-report.md`。
- 如果运行月份是 10 月，目标报告期是当年 Q3，文件名为 `YYYY-q3-quarterly-deep-macro-report.md`。
- 如果目标文件已经存在，直接结束；不要覆盖、不要 commit、不要 push。
- 不要把生成报告写入 `docs/` 或 `knowledge/`。

### 3. 生成、提交与推送

- 先检查 `git status --short`，识别运行前已有的改动，后续不要 stage 或提交这些既有改动。
- 按下方“报告生成规范”生成完整中文 Markdown 报告，并写入目标文件。
- 只 stage 新生成的目标报告文件，不要 stage prompt、README、`docs/`、`knowledge/` 或其他现有改动。
- commit message 使用：`Add quarterly macro report for YYYY QX`，其中 `YYYY QX` 是目标报告期。
- commit 成功后必须 push 当前分支；如果当前分支没有 upstream，使用 `git push -u origin HEAD`。
- 如果没有新报告文件，或目标文件已存在，不要创建空 commit。
- 如果 push 失败，保留已创建的报告和 commit，并在 automation 输出中说明失败原因。

## 报告生成规范

当进入报告生成阶段时，请生成一份中文季度深度宏观经济分析报告，不要询问用户确认。

## 一、共同报告体系说明

你要为用户长期维护一个宏观经济观察体系。这个体系分为三类报告：

1. 月度经济脉搏报告

目标是快速判断最新一个月是否出现经济拐点、政策变化、就业压力、消费变化、房地产变化、价格变化或外部冲击。月报要短而密，不做冗长历史回顾。

2. 季度深度宏观报告

目标是基于季度 GDP、居民收入、消费、投资、就业、地产、外贸、价格、政策和国际比较，判断经济结构是否发生变化。季报是主报告。

3. 年度战略经济报告

目标是基于全年数据和长期结构，分析中国大陆经济的长期趋势、全球位置、民生变化、产业升级、房地产、人口、就业、财政、居民资产负债表，以及未来 1—5 年情景。
本任务是其中的“季度深度宏观报告”。

## 二、报告主轴

报告主角是中国大陆经济。请注意：

- 不要把中国大陆、中国香港、中国台湾混为一谈。
- 中国大陆是分析主体。
- 美国、欧元区/欧盟、日本、韩国、印度是固定比较对象。
- 其他经济体按照重要性和当季事件选择性纳入。

经济体分层如下：
第一层，固定核心，每次都要覆盖：

- 中国大陆
- 美国
- 欧元区/欧盟
- 日本
- 韩国
- 印度

第二层，按季度、年度或重大事件纳入：

- ASEAN / 越南 / 印度尼西亚
- 台湾
- 德国
- 英国
- 墨西哥
- 巴西
- GCC / 中东能源经济体

第三层，只在发生重大事件时纳入：

- 俄罗斯
- 澳大利亚
- 加拿大
- 土耳其
- 阿根廷
- 南非
- 其他有重大金融、能源、战争、债务、汇率、供应链事件的经济体

## 三、数据和来源规则

请在输出报告前进行联网检索，并尽量使用最新数据。优先级如下：

1. 官方统计机构：
2. 中国国家统计局、中国人民银行、海关总署、人社部、财政部
3. 美国 BLS、BEA、Federal Reserve、Census Bureau
4. Eurostat、ECB
5. 日本 Statistics Bureau、Bank of Japan、Cabinet Office
6. 韩国 Statistics Korea、Bank of Korea、Ministry of Economy and Finance
7. 印度 MOSPI、RBI、财政部
8. 国际机构：
9. IMF World Economic Outlook
10. World Bank Global Economic Prospects
11. OECD Economic Outlook
12. BIS、ILO、WTO、UNCTAD、IEA 等
13. 高质量财经媒体和新闻源：
14. Reuters、Bloomberg、Financial Times、WSJ、Nikkei Asia、The Economist 等
15. 媒体主要用于解释最新事件、市场反应和政策背景，不要用媒体替代官方统计数据。

请严格遵守：

- 每一个关键数据都要注明数据对应的月份、季度或年份。
- 如果本季度或本月数据尚未发布，要明确写“尚未发布”，并使用最新可得数据。
- 不要编造尚未发布的数据。
- 如果不同来源口径不一致，要解释口径差异。
- 区分事实、推断和预测。
- 所有关键事实、数据、政策和机构预测都要附带引用。
- 不要只堆数据，要解释数据背后的经济含义。
- 注意数据修订。季度 GDP、就业、通胀、贸易和房地产数据可能后续修订。

## 四、分析原则

每份报告都要同时包含：

1. 结构化分析

拆分增长、消费、投资、房地产、外贸、就业、收入、物价、政策、金融条件和全球比较。

2. 现象分析

解释普通人的体感：就业难不难、工资稳不稳、房价和租金如何影响家庭、物价是否真正缓解生活压力、消费为什么强或弱、居民为什么储蓄或加杠杆。

3. 趋势分析

至少区分：

4. 短期：未来 1 个季度
5. 中期：未来 2—4 个季度
6. 长期：未来 3—5 年的结构趋势
7. 国际比较

不要机械罗列国家数据，而要比较经济周期位置：

8. 谁是需求强但通胀高？
9. 谁是增长弱但就业稳？
10. 谁依赖出口？
11. 谁受房地产、债务、人口、能源价格影响更大？
12. 谁的政策空间更大？
13. 民生重点

必须涵盖：

14. 就业总量
15. 青年就业或毕业生就业压力
16. 工资和收入预期
17. 消费信心
18. 房地产和居民财富
19. 物价与生活成本
20. 社保、养老、医疗、教育等长期支出预期
21. 城市中产、年轻人、低收入群体、小微企业主的不同体感
22. 洞察输出

每份报告都要有明确 insights，而不是只有数据总结。请指出：

23. 最重要的新变化是什么？
24. 哪些变化只是噪音？
25. 哪些变量最值得继续观察？
26. 当前主流叙事可能哪里错了？
27. 普通人的体感为什么可能和宏观数据不同？

## 五、季度报告专项指令

本报告是“季度深度宏观报告”。
推荐报告时间为每年 1 月、4 月、7 月、10 月的下旬。季度报告应基于中国大陆最新季度 GDP 和主要季度数据，同时结合美国、欧元区/欧盟、日本、韩国、印度的最新可得季度或月度数据。
季度报告是整个体系的主报告。请写得比月报更深入，但不要写成年报。它要回答：

- 中国大陆经济是否在真实修复？
- 增长由什么驱动？
- 消费、投资、房地产、出口之间的结构是否改善？
- 居民收入和消费是否匹配？
- 就业是总量稳定还是质量改善？
- 政策是否有效传导到居民、企业和地方财政？
- 中国与美国、欧元区、日本、韩国、印度相比，经济周期位置有何不同？
- 未来一个季度和未来一年最大的风险是什么？

请特别处理四个季度的差异：

1. 1 月季度报告
2. 分析上一年第四季度和全年初步数据。
3. 但不要替代 3 月年度战略报告。
4. 如果年度统计公报尚未发布，请明确说明。
5. 重点是判断上一年收官状态和新一年开局压力。
6. 4 月季度报告
7. 分析一季度数据。
8. 结合 IMF 4 月 World Economic Outlook，如已经发布。
9. 重点是判断全年增长目标是否有压力，以及政策是否需要加码。
10. 7 月季度报告
11. 分析二季度和上半年数据。
12. 这份报告要额外加入“上半年特别章节”。
13. 结合 World Bank 6 月 Global Economic Prospects 和 OECD 6 月 Economic Outlook，如已发布。
14. 重点是判断全年路径是否需要修正。
15. 10 月季度报告
16. 分析三季度和前三季度数据。
17. 结合 IMF 10 月 World Economic Outlook，如已发布。
18. 重点是判断全年能否完成目标，以及下一年宏观政策可能如何布局。

## 六、季度报告输出结构

请按以下结构输出：

### 标题

格式建议： 《全球与中国大陆季度深度宏观报告：YYYY 年第 X 季度》

0. 数据基准与数据完整性说明

用表格说明：

- 报告日期
- 中国大陆最新 GDP 数据
- 中国大陆最新消费、投资、房地产、外贸、就业、价格数据
- 美国最新 GDP、就业、通胀、消费数据
- 欧元区最新 GDP、就业、通胀、PMI 和 ECB 信息
- 日本最新 GDP、就业、通胀、工资和 BOJ 信息
- 韩国最新 GDP、出口、就业、通胀和 BOK 信息
- 印度最新 GDP、通胀、工业或 PMI、RBI 信息
- IMF / World Bank / OECD 最新报告是否已经发布
- 哪些关键数据尚未发布
1. 概念图

用 ASCII 画一个简短概念图，说明本季度宏观分析处在哪个框架里。建议类似：
宏观经济诊断 ├─ 周期层：GDP / 消费 / 投资 / 外贸 / 通胀 / 就业 ├─ 结构层：房地产 / 人口 / 地方财政 / 民营投资 / 制造升级 ├─ 民生层：收入 / 就业质量 / 房价 / 物价 / 社保预期 └─ 国际层：美国 / 欧元区 / 日本 / 韩国 / 印度 / 全球风险

2. 执行摘要

用 5—8 条 bullet 输出核心结论。必须包括：

- 中国大陆当前经济状态
- 与上一季度相比的变化
- 最大支撑项
- 最大拖累项
- 民生体感
- 国际比较中最重要的差异
- 未来一个季度最重要的不确定性
3. 中国大陆宏观总览

分析：

- GDP 增速和环比动能
- 第一、第二、第三产业表现
- 消费、资本形成、净出口对增长的贡献
- 工业、服务业、高技术制造
- 经济是否呈现“生产强、需求弱”或其他结构特征
4. 需求侧分析

分小节：

- 消费：社零、服务消费、耐用品、餐饮、线上消费、居民消费倾向
- 投资：固定资产投资、制造业投资、基建、民间投资
- 房地产：开发投资、销售、价格、库存、保交楼、居民财富效应
- 外贸：出口、进口、贸易结构、机电产品、高技术产品、贸易摩擦
5. 供给侧和产业结构

分析：

- 工业生产
- 高技术制造
- 装备制造
- 新能源、汽车、电子、机器人、半导体、AI 基建等
- 传统行业和产能过剩压力
- 企业利润和价格战
- 产业升级是否有效带动就业和收入
6. 就业、收入与民生

这是重点章节。必须覆盖：

- 城镇调查失业率
- 青年就业、毕业生就业、白领就业、蓝领就业
- 工资和收入增长
- 城乡收入差异
- 居民消费支出
- 房价和家庭资产负债表
- 物价和生活成本
- 教育、医疗、养老、住房等长期压力
- 不同群体体感差异

请明确解释：

- 为什么宏观 GDP 与普通人体感可能不同？
- 就业是数量问题、质量问题，还是预期问题？
- 居民为什么消费、储蓄或还债？
7. 价格、金融与政策

分析：

- CPI、核心 CPI、PPI
- 通胀、通缩或低通胀压力
- 企业成本和利润
- 货币政策：利率、LPR、存款准备金率、信贷、社融
- 财政政策：专项债、中央财政、地方债务、转移支付
- 房地产政策
- 消费刺激和产业政策
- 政策是否真正传导到居民和企业
8. 国际比较

固定比较：

- 中国大陆 vs 美国
- 中国大陆 vs 欧元区/欧盟
- 中国大陆 vs 日本
- 中国大陆 vs 韩国
- 中国大陆 vs 印度

每组比较至少回答：

- 增长动能谁更强？
- 通胀压力谁更大？
- 就业压力谁更明显？
- 居民体感谁更好或更差？
- 政策空间谁更大？
- 这个经济体对中国大陆意味着什么？

根据当季情况，选择性加入：

- ASEAN / 越南 / 印尼
- 台湾
- 德国
- 英国
- 墨西哥
- 巴西
- GCC / 中东
- 俄罗斯、澳大利亚、加拿大、土耳其、阿根廷、南非等事件驱动经济体
9. 全球机构视角

如果 IMF、World Bank、OECD、BIS、ILO、WTO 等有最新报告，请总结其与本季度相关的判断。不要只复制机构观点，要评价：

- 它们如何看中国大陆？
- 它们如何看美国、欧元区、日本、韩国、印度？
- 它们是否下调或上调预测？
- 它们强调了哪些风险？
- 这些判断与你的数据分析是否一致？
10. 短期与中期趋势

请分别给出：

- 未来 1 个季度判断
- 未来 2—4 个季度判断
- 未来 3—5 年需要关注的结构趋势

每个判断都要说明：

- 基准情景
- 乐观情景
- 悲观情景
- 触发条件
11. 现象分析

用更贴近日常生活和商业体感的方式解释本季度经济。可以包括：

- 为什么很多人觉得经济比 GDP 更差？
- 为什么出口好不一定带来居民消费强？
- 为什么低通胀不一定代表民生改善？
- 为什么房地产稳定比房地产反弹更重要？
- 为什么高技术制造强不一定自动解决青年就业？
- 为什么民营企业和小微企业体感可能弱于宏观数字？
12. 最重要 insights

输出 8—12 条真正值得记住的洞察。每条都要有判断，不要写成事实罗列。

13. 下季度观察清单

列出 8—12 个观察点：

- 指标或事件
- 为什么重要
- 改善意味着什么
- 恶化意味着什么
14. 结论

用清晰判断总结：

- 中国大陆处于什么经济阶段
- 这是一种全面复苏、分化复苏、结构转型，还是风险修复？
- 最重要的民生变量是什么？
- 最重要的政策变量是什么？
- 与美国、欧元区、日本、韩国、印度相比，中国大陆最突出的问题和优势是什么？
