# 年度战略经济报告 Prompt

## Automation 执行协议

本文件用于 Codex cron automation。automation 应每周五 11:30 按安装时确认的 IANA 时区运行一次。每次运行时必须使用 automation 外层 prompt 指定的时区判断日期；如果外层 prompt 未指定时区，默认使用 `America/New_York`。

### 1. 运行窗口

- 只在每年 3 月 1 日至 15 日之间生成年报。
- 如果不在窗口内，直接结束；不要写文件、不要 commit、不要 push。
- 如果已经进入窗口，但关键数据尚未发布，仍然生成报告，并在报告的“数据基准与完整性说明”中明确写“尚未发布”。

### 2. 目标年份、目标文件与去重

- 输出目录：`macro-reports/`。
- 目标报告年份是运行当天所在年份的上一年。
- 文件名：`YYYY-annual-strategic-economic-report.md`，其中 `YYYY` 是目标报告年份。
- 如果目标文件已经存在，直接结束；不要覆盖、不要 commit、不要 push。
- 不要把生成报告写入 `docs/` 或 `knowledge/`。

### 3. 生成、提交与推送

- 先检查 `git status --short`，识别运行前已有的改动，后续不要 stage 或提交这些既有改动。
- 按下方“报告生成规范”生成完整中文 Markdown 报告，并写入目标文件。
- 只 stage 新生成的目标报告文件，不要 stage prompt、README、`docs/`、`knowledge/` 或其他现有改动。
- commit message 使用：`Add annual macro report for YYYY`，其中 `YYYY` 是目标报告年份。
- commit 成功后必须 push 当前分支；如果当前分支没有 upstream，使用 `git push -u origin HEAD`。
- 如果没有新报告文件，或目标文件已存在，不要创建空 commit。
- 如果 push 失败，保留已创建的报告和 commit，并在 automation 输出中说明失败原因。

## 报告生成规范

当进入报告生成阶段时，请生成一份中文年度战略宏观经济分析报告，不要询问用户确认。

## 一、共同报告体系说明

你要为用户长期维护一个宏观经济观察体系。这个体系分为三类报告：

1. 月度经济脉搏报告

目标是快速判断最新一个月是否出现经济拐点、政策变化、就业压力、消费变化、房地产变化、价格变化或外部冲击。月报要短而密，不做冗长历史回顾。

2. 季度深度宏观报告

目标是基于季度 GDP、居民收入、消费、投资、就业、地产、外贸、价格、政策和国际比较，判断经济结构是否发生变化。季报是主报告。

3. 年度战略经济报告

目标是基于全年数据和长期结构，分析中国大陆经济的长期趋势、全球位置、民生变化、产业升级、房地产、人口、就业、财政、居民资产负债表，以及未来 1—5 年情景。
本任务是其中的“年度战略经济报告”。

## 二、报告主轴

报告主角是中国大陆经济。请注意：

- 不要把中国大陆、中国香港、中国台湾混为一谈。
- 中国大陆是分析主体。
- 美国、欧元区/欧盟、日本、韩国、印度是固定比较对象。
- 其他经济体按照重要性和年度事件选择性纳入。

经济体分层如下：
第一层，固定核心，每次都要覆盖：

- 美国
- 欧元区/欧盟
- 日本
- 韩国
- 印度

第二层，年度报告中原则上应该覆盖，但深度可按重要性调整：

- ASEAN / 越南 / 印度尼西亚
- 台湾
- 德国
- 英国
- 墨西哥
- 巴西

第三层，只在年度发生重大事件时纳入：

- 阿根廷
- 南非
- 其他有重大金融、能源、战争、债务、汇率、供应链事件的经济体

## 四、分析原则

每份报告都要同时包含：

1. 结构化分析

拆分增长、消费、投资、房地产、外贸、就业、收入、物价、政策、金融条件和全球比较。

2. 现象分析

解释普通人的体感：就业难不难、工资稳不稳、房价和租金如何影响家庭、物价是否真正缓解生活压力、消费为什么强或弱、居民为什么储蓄或加杠杆。

3. 趋势分析

年报必须区分：

4. 短期：未来 1 年
5. 中期：未来 2—3 年
6. 长期：未来 3—5 年，必要时延伸到 10 年结构趋势
7. 国际比较

不要机械罗列国家数据，而要比较经济周期位置和长期结构：

8. 谁的人口结构更有利？
9. 谁的生产率提升空间更大？
10. 谁的债务约束更强？
11. 谁的产业升级更真实？

13. 谁的政策空间更大？
14. 谁在全球供应链和资本流动中受益或受损？
15. 民生重点

必须涵盖：

16. 就业总量

18. 工资和收入预期

24. 洞察输出

## 五、年度报告专项指令

本报告是“年度战略经济报告”。
推荐报告时间为每年 3 月初。原因是中国大陆年度统计公报通常在 2 月底前后发布，3 月初更适合获得较完整的上一年度人口、收入、消费、产业、房地产、就业、财政和民生数据。此时美国、欧元区、日本、韩国、印度以及IMF、World Bank、OECD 的部分年度或最新预测数据也更完整。
