# 月度经济脉搏报告 Prompt

## Automation 执行协议

本文件用于 Codex cron automation。automation 应每周五 09:30 按安装时确认的 IANA 时区运行一次。每次运行时必须使用 automation 外层 prompt 指定的时区判断日期；如果外层 prompt 未指定时区，默认使用 `America/New_York`。

### 1. 运行窗口

- 只在每月 22 日至 28 日之间生成月报。
- 如果不在窗口内，直接结束；不要写文件、不要 commit、不要 push。
- 如果已经进入窗口，但关键数据尚未发布，仍然生成报告，并在报告的“数据基准与未发布数据说明”中明确写“尚未发布”。

### 2. 目标文件与去重

- 输出目录：`macro-reports/`。
- 文件名：`YYYY-MM-monthly-economic-pulse-report.md`，其中 `YYYY-MM` 是运行当天所在月份。
- 如果目标文件已经存在，直接结束；不要覆盖、不要 commit、不要 push。
- 不要把生成报告写入 `docs/` 或 `knowledge/`。

### 3. 生成、提交与推送

- 先检查 `git status --short`，识别运行前已有的改动，后续不要 stage 或提交这些既有改动。
- 按下方“报告生成规范”生成完整中文 Markdown 报告，并写入目标文件。
- 只 stage 新生成的目标报告文件，不要 stage prompt、README、`docs/`、`knowledge/` 或其他现有改动。
- commit message 使用：`Add monthly macro report for YYYY-MM`。
- commit 成功后必须 push 当前分支；如果当前分支没有 upstream，使用 `git push -u origin HEAD`。
- 如果没有新报告文件，或目标文件已存在，不要创建空 commit。
- 如果 push 失败，保留已创建的报告和 commit，并在 automation 输出中说明失败原因。

## 报告生成规范

当进入报告生成阶段时，请生成一份中文宏观经济月度分析报告，不要询问用户确认。

## 一、共同报告体系说明

你要为用户长期维护一个宏观经济观察体系。这个体系分为三类报告：

1. 月度经济脉搏报告

目标是快速判断最新一个月是否出现经济拐点、政策变化、就业压力、消费变化、房地产变化、价格变化或外部冲击。月报要短而密，不做冗长历史回顾。

2. 季度深度宏观报告

目标是基于季度 GDP、居民收入、消费、投资、就业、地产、外贸、价格、政策和国际比较，判断经济结构是否发生变化。季报是主报告。

3. 年度战略经济报告

目标是基于全年数据和长期结构，分析中国大陆经济的长期趋势、全球位置、民生变化、产业升级、房地产、人口、就业、财政、居民资产负债表，以及未来 1—5 年情景。
本任务是其中的“月度经济脉搏报告”。

## 二、报告主轴

报告主角是中国大陆经济。请注意：

- 不要把中国大陆、中国香港、中国台湾混为一谈。
- 中国大陆是分析主体。
- 美国、欧元区/欧盟、日本、韩国、印度是固定比较对象。
- 其他经济体按照重要性和当月事件选择性纳入。

经济体分层如下：
第一层，固定核心，每次都要覆盖：

- 中国大陆
- 美国
- 欧元区/欧盟
- 日本
- 韩国
- 印度

第二层，按季度、年度或重大事件纳入：

- ASEAN / 越南 / 印度尼西亚
- 台湾
- 德国
- 英国
- 墨西哥
- 巴西
- GCC / 中东能源经济体

第三层，只在发生重大事件时纳入：

- 俄罗斯
- 澳大利亚
- 加拿大
- 土耳其
- 阿根廷
- 南非
- 其他有重大金融、能源、战争、债务、汇率、供应链事件的经济体

## 四、分析原则

每份报告都要同时包含：

1. 结构化分析

拆分增长、消费、投资、房地产、外贸、就业、收入、物价、政策、金融条件和全球比较。

2. 现象分析

解释普通人的体感：就业难不难、工资稳不稳、房价和租金如何影响家庭、物价是否真正缓解生活压力、消费为什么强或弱、居民为什么储蓄或加杠杆。

3. 趋势分析

至少区分：

4. 短期：未来 1—3 个月
5. 中期：未来 3—12 个月 月报不需要展开长期十年判断，但可以指出是否与长期结构矛盾有关。
6. 国际比较

不要机械罗列国家数据，而要比较经济周期位置：

7. 谁是需求强但通胀高？
8. 谁是增长弱但就业稳？
9. 谁依赖出口？
10. 谁受房地产、债务、人口、能源价格影响更大？
11. 谁的政策空间更大？
12. 民生重点

必须涵盖：

13. 就业总量
14. 青年就业或毕业生就业压力
15. 工资和收入预期
16. 消费信心
17. 房地产和居民财富
18. 物价与生活成本
19. 社保、养老、医疗、教育等长期支出预期
20. 城市中产、年轻人、低收入群体、小微企业主的不同体感
21. 洞察输出

每份报告都要有明确 insights，而不是只有数据总结。请指出：

22. 最重要的新变化是什么？
23. 哪些变化只是噪音？
24. 哪些变量最值得继续观察？
25. 当前主流叙事可能哪里错了？
26. 普通人的体感为什么可能和宏观数据不同？

## 六、月度报告输出结构

请按以下结构输出：

### 标题

格式建议： 《全球与中国大陆月度经济脉搏报告：YYYY 年 MM 月》

0. 数据基准与未发布数据说明

用简短表格列出：

- 报告日期
- 中国大陆最新月度数据月份
- 中国大陆最新季度 GDP
- 美国最新就业和通胀数据
- 欧元区最新通胀和就业数据
- 日本最新通胀和就业数据
- 韩国最新通胀和就业数据
- 印度最新通胀和增长数据
- 尚未发布但需要等待的数据
1. 一句话核心判断

用 1—3 句话说明本月最重要的宏观结论。

2. 本月最重要的 3—5 个变化

每个变化都要说明：

- 发生了什么
- 为什么重要
- 是短期噪音还是趋势信号
- 对中国大陆民生或全球经济有什么影响
3. 中国大陆经济脉搏

分小节：

- 增长与生产
- 消费与居民需求
- 投资与房地产
- 外贸与制造业
- 就业与收入
- 物价与企业利润压力
- 政策与金融条件
4. 民生体感分析

不要只写宏观数据。请解释：

- 普通城市居民的体感
- 年轻人和毕业生的体感
- 中产家庭的住房和消费压力
- 低收入群体的生活成本
- 小微企业和个体户的经营压力
- 为什么宏观数据和体感可能不同
5. 国际比较

固定比较：

- 中国大陆 vs 美国
- 中国大陆 vs 欧元区/欧盟
- 中国大陆 vs 日本
- 中国大陆 vs 韩国
- 中国大陆 vs 印度

请不要机械罗列，要比较周期位置、政策空间和民生压力。

6. 本月全球风险与外部变量

包括但不限于：

- 美联储、ECB、BOJ、BOK、RBI 政策
- 美债收益率、美元、汇率
- 油价、天然气、粮食、金属
- 地缘政治和贸易摩擦
- 全球 AI、半导体、能源转型、供应链重组
7. 未来 1—3 个月观察清单

列出 5—8 个最值得观察的指标或事件。 每个指标说明：

- 为什么要看
- 如果改善意味着什么
- 如果恶化意味着什么
8. 最重要 insights

用 5—8 条 bullet 输出本月真正值得记住的洞察。

9. 结论

用简洁但有判断力的方式总结：

- 中国大陆当前处于什么经济状态
- 与上月相比是改善、恶化还是分化
- 短期最重要的不确定性是什么
